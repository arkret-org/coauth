# `doctor`

运行部署诊断，帮助发现常见的配置和部署问题。

## 用法

```bash
coauth doctor -c config.yaml
```

## 检查项目

`doctor` 命令执行以下诊断：

- **数据库连通性** — 验证 PostgreSQL 数据库是否可达
- **配置有效性** — 检查配置文件的语法和语义
- **模板渲染** — 确保所有模板可以正常加载和渲染
- **密钥材料** — 验证签名密钥是否存在且可用
- **Homeserver 可达性** — 测试与 Matrix homeserver 的连接

## 输出说明

每个检查项显示一个状态：

- **OK** — 检查通过
- **WARN** — 检测到潜在问题，服务可能仍能运行
- **FAIL** — 发现严重问题，服务可能无法正常工作

## 使用建议

- 每次修改配置后运行 `doctor` 验证设置
- 使用 `RUST_LOG=debug` 获取更详细的诊断输出
